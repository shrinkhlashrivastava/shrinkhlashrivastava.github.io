BEFORE PUBLISHING
1. Search/replace YOUR_EMAIL@example.com.
2. Replace YOUR_RESUME_PDF.pdf.
3. Add exact employment dates on /resume/.
4. Replace placeholder boxes with real images.
   Put images in /assets/images/ and replace a placeholder with:
   <div class="media"><img src="/assets/images/your-file.png" alt="Description"></div>

DEPLOY
- Netlify: unzip and drag the entire folder into Netlify Drop.
- Vercel: put the folder in GitHub, import it into Vercel, choose Framework = Other, no build command.
- GitHub Pages: push the files and enable Pages.

RECOMMENDED FOR YOUR CURRENT SITUATION
Keep the existing Framer URL live while you refresh it. Do not change the URL printed on resumes during an urgent update.
Use this package as a staging/reference site, or deploy it separately as a preview.
If you later move to a custom domain, that domain can remain stable even if you change hosting platforms.
